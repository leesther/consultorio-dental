# Consultorio Dental

Sistema web de gestión para consultorio dental, diseñado bajo una arquitectura modular para escalar la gestión de pacientes, citas y tratamientos.

## Estructura del Proyecto
- `/backend-api`: Lógica del servidor y endpoints.
- `/database`: Esquemas y scripts de base de datos.
- `/frontend-portal-paciente`: Interfaz para pacientes.
- `/frontend-sistema-administrativo`: Panel de gestión clínica.
- `/docs`: Documentación técnica del proyecto.
